### Selected work: AI & Search

| Project | Summary | Stack |
|---|---|---|
| **Semantic Document Search (RAG)** | Natural-language Q&A over PDFs, Word files and scans, with citations. Hybrid dense + BM25 retrieval fused with RRF. 10K+ queries/day at under 2s. | LangChain · GPT-4o · Pinecone · FastAPI · AWS Lambda |
| **Fine-tuned Support LLM** | LLaMA-3.1-8B tuned with QLoRA, FAISS knowledge base, confidence-based human handoff. Serves 200+ concurrent users at 60 tok/s. | HuggingFace · QLoRA · vLLM · FAISS |
| **Patent Search Engine** | 160M+ patent records with BM25 field boosting and SBERT semantic re-ranking. Sub-second P95 latency. | Elasticsearch · SBERT · Django · React |
| **Sentiment & Recommendation Engine** | BERT sentiment classifier (F1 0.91) with neural collaborative filtering and built-in A/B testing. P99 under 80ms. | BERT · Scikit-learn · FastAPI · Redis |
| **Demand Forecasting** | Prophet + LSTM hybrid across 500+ SKUs that triggers purchase orders automatically. MAPE 6.2%. | Prophet · LSTM · Pandas · Plotly |
